## 四、验证口径备忘

- 源码 CRLF：多行断言统一归一化 `\r\n` → `\n`，否则全部假失配。
- C# 界面串按 **#US 堆 UTF-16LE** 命中；类型名按 **#Strings 堆 UTF-8**；自包含 exe 是压缩 bundle，
  要读 `obj/Release/net8.0/win-x64/*.dll` 而不是 exe 字节。
- NRO 界面串按 **UTF-8 C 串 + `\0` 结尾**精确匹配；运行时拼接的标题要拆成多个字面量分别断言。
- 二进制里 `已解包\0` 会命中 UI 结果行 `%s 已解包` 的尾部子串，不能据此判「中文路径残留」。
- 改了 C++ 源码必须删对应 `_obj/main_N.o`（索引 = `sorted(core+app+nx *.cpp)`），否则静默跳过重编。
