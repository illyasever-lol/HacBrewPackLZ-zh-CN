# Security

If you find a security problem in hacBrewPackLZ, report it in a [confidential issue](https://gitlab.com/ismaellozanoperezserrano/hacbrewpacklz/-/issues/new?issue[confidential]=true) on GitLab, which only the project's maintainers can read. Examples are a game file or a network answer that makes the app do something it shouldn't, or the updater accepting a version the project didn't sign.

Leave your keys out of it. The app never needs them sent anywhere, and a report about keys only needs to say what happened.

Fixes go into the newest version, or into a quick release of their own when they can't wait. Each version updates itself, and only installs versions signed with the project's key.
